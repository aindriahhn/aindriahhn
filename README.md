# Katabatic Vector

Katabatic Vector is a one-person studio developing games and tools entirely on Android, in a way designed and intended to be extremely portable.

Currently building **Distant Depths**, a survival roguelike about descent: escape a dying orbital station, ride the pod down, and learn what the dark keeps. Philosophy in the mechanics.

Also the **Telos** toolchain that builds it: Choros, Kinetoglyphs, Katabasis, and CALORIS — single-file creative tools. No install, no account, no internet.

## Play

- **WARM** — a compact dungeon crawler. A wizard, low on hit points, descending anyway. Free on itch.io: https://katabatic-vector.itch.io/warm
- **CALORIS** — an AI-ready sound engine and composition environment: https://katabatic-vector.itch.io/caloris
- Everything else lives at https://katabatic-vector.itch.io

## The catalogue, here

- [WARM](https://github.com/aindriahhn/WARM) — the shipped game, standard build
- [CALORIS-AI-READY-SOUND-ENGINE](https://github.com/aindriahhn/CALORIS-AI-READY-SOUND-ENGINE) — music engine and composition tool
- [Kinetoglyphs](https://github.com/aindriahhn/Kinetoglyphs) — ANSI/cell animation and sprite authoring
- [Choros](https://github.com/aindriahhn/Choros) — scene and space authoring
- [Katabasis](https://github.com/aindriahhn/Katabasis) — behaviour and entity authoring

Everything ships as a single self-contained HTML file. Download it, keep it, it's yours.
